# ElytraFinder

[English](README.md) · [Deutsch](README.de.md)

**Author:** zqxyaa4k

A client-side Fabric mod for Minecraft **26.2** that searches for nearby End Cities with ships using a world seed and the player's current position in the End.

## Download

**[Download the latest ElytraFinder JAR from GitHub Releases](https://github.com/zqxyaa4k/ElytraFinder/releases/latest)**

Each GitHub Release contains the ready-to-install mod JAR. You do not need to compile the source code yourself.

To get the JAR from a normal development build, open the repository's **Actions** tab, select the latest successful **Build** run, and download the artifact whose name starts with `ElytraFinder-JAR-`.

## Language selection

On first launch, ElytraFinder asks you to choose **Deutsch** or **English**. Your choice is saved locally and is used by the main screen, HUD and saved-seeds screen. You can switch languages at any time with the **DE / EN** button in the Finder screen.

## Features

- Finds End Cities with ships around the player's current X/Z position in the End.
- Shows the five closest results in a live HUD and keeps their distances ordered from the player's current position.
- Checks the ship area for an Elytra in an item frame when the relevant chunks are loaded. The status can be unknown until the area is loaded.
- Saves named world seeds locally and remembers the last-used seed.
- Opens with **J** (the key can be changed in Minecraft's Controls settings).
- Provides teleport buttons in **singleplayer only**. The buttons are disabled in multiplayer.

## Requirements

| Component | Version |
|---|---|
| Minecraft | 26.2 |
| Java | 25 or newer |
| Fabric Loader | 0.20.1 or newer |
| Fabric API | 0.161.0+26.2 |

This is a **client-side** mod. To search a world, enter its numeric seed and be in the End so the search can use your current position. In multiplayer, you need to know the world seed; the mod does not retrieve a hidden server seed for you.

## Install

1. Install Fabric Loader for Minecraft 26.2.
2. Install the matching Fabric API version.
3. Download the ElytraFinder JAR from [GitHub Releases](https://github.com/zqxyaa4k/ElytraFinder/releases/latest).
4. Put the JAR into your Minecraft `mods` folder.
5. Start Minecraft with the Fabric profile.

## Build from source

```bash
./gradlew build
```

On Windows PowerShell:

```powershell
.\gradlew.bat build
```

The compiled mod JAR is written to `build/libs/`. This folder is generated by Gradle and intentionally is not committed to the source repository. GitHub Actions builds the JAR automatically; tagged releases attach it as a direct download.

## Create a release (maintainers)

After pushing the source code to the `main` branch, create and push a version tag to trigger an automatic build and GitHub Release:

```bash
git tag v1.0.0
git push origin v1.0.0
```

The release workflow builds the mod with Java 25 and attaches the distributable JAR to the GitHub Release.
